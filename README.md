# Gold-Price-Analysis-India-2000-2025-
📊 Gold Price Analysis (India, 2000–2025) — Visualizes gold price trends, inflation-adjusted values, and compares gold vs FD returns using interactive Plotly charts. Built with Python, pandas, and Jupyter Notebook.
This project explores how gold prices in India evolved over the last 25 years (2000–2025) using data analysis and visualization techniques. It highlights the price trend, adjusts for inflation, and compares gold investment growth with traditional fixed deposit (FD) returns.

---

## 🔍 Key Insights

- 📈 Tracked gold price trends from ₹4,400 (2000) to ₹63,000+ (2025)  
- 💸 Adjusted gold prices for inflation to reflect true value  
- 🏦 Compared returns of ₹10,000 invested in gold vs FD over time  
- 📊 All visualizations created using interactive Plotly graphs
